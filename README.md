# Level Planr

An isometric and top-down level planner for game designers: rooms, furniture, doors, custom shapes and multi-level layouts. Single static page, no build step, no dependencies. Installable as an app and works offline.

## Run it
Open `index.html`, or host the folder. On GitHub Pages: **Settings → Pages → Deploy from branch → `main` / root**.

## Highlights
- Choose **Isometric** or **Top-down** per project (switch any time with `V`).
- Cubes, extruded faces, arrows, text, dots, icons, doors, shapes and custom polygon shapes.
- Right-click any item for its settings; double-click text or a label (or `F2`) to rename.
- Export/Import projects as `.levelplanr.json` to share; export the view as PNG.
- Press `?` for all shortcuts.
